# Impala67

Impala67 ist eine installierbare, local-first Progressive Web App für Notizen, PDFs, Handschrift, Karteikarten und KI-gestütztes Lernen.

## Impala67 öffnen

[Zur App](https://prinzpuma.github.io/Impala67/)

## Funktionen

- Notizen und Dokumente direkt im Browser verwalten
- Handschrift und PDFs integrieren
- Karteikarten und Lerninhalte erstellen
- Offline arbeiten dank PWA-Unterstützung
- Daten lokal im Browser speichern
- Optional mit Google Drive synchronisieren

Impala67 benötigt keine Desktop-Installation und funktioniert auf modernen Browsern sowie als installierte PWA.
